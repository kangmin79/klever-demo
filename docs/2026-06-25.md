## 1) 종이책 — 찾아줘북즈 예약 + 반납 예약 (✅완성)
- Edge Fn `semyung-reserve`(클레버/supabase/functions, 배포): action `reserve|list|cancel`(찾아줘북즈=대출가능본 서가픽업) + `hold|holdlist|unhold`(반납예약=대출중 순번대기).
- 로그인=`POST lib.semyung.ac.kr/login`(평문 id/password). 찾아줘북즈=`POST /loanreq/request`{controlno,main_no,accession_no,receive_location:0001}. 반납예약=`POST /search/reserve/request`{mainno,location}. 취소=`/loanreq/cancel`·`/myreserve/cancel`(checkbox=seq).
- app.html `loadHolding`: 대출가능→`smConfirm`→`smReserve` / 대출중→`smHoldConfirm`→`smHold`. 예약 직전 확인시트(.rsv-sheet, 규칙 라벨칩, 이모지無). 외부 OPAC "종이책 대출하기"는 isPaperHold면 숨김(일원화). 소장현황 보존서고 제외(빌릴수있는 권수만, 4/4=N권모두).
- E2E검증 완료(예약→현황→취소 0건).

## 2) 구매 전자책 — 대출→교보 DRM뷰어 읽기 (✅완성, ~8,900권)
- Edge Fn `semyung-ebook-borrow`(배포): action `borrow|return|status`.
- ⚠️**전자도서관(ebook.semyung.ac.kr)은 OPAC와 별개 시스템, AES 로그인**: aes.js `mysqlAES`=표준 AES-128-ECB, key="freedom"+널패딩(16B), PKCS7, 대문자hex. Deno엔 ECB없어 AES-CBC IV=0 블록별 첫16B로 구현. 검증 `03251`→`F00D228B7D1C8437C2222248B6383DBB`. 로그인=`POST /elibrary-front/member/loginProcess.json`{mmbrId:AES(id),pwd:AES(pw)}→rtnCode:T.
- 대출=`POST /process/contentBorrowProc.xml`{lbryCode:20213,brcd,dvsnCode:W}→loanSrmb+entsDvsnCode(KB교보/YS예스24). 반납=`/process/contentReturnProc.xml`{lbryCode,loanSrmb}.
- **뷰어(핵심돌파)**: sessionAddProc→`GET /process/webViewerProc.xml`→`<webViewrUrl>`(wviewer.kyobobook.co.kr/goViewer/{brcd}/{brcd})+`<token>`. 진입=`/popup/popWebviewer.ink?webViewrUrl=&title=&token=`(토큰 `/`→`-`). **쿠키 없이 302→교보 ePubViewer 직행=완전 단독실행**. YES24책도 같은 교보 통합뷰어로 서비스(둘 다 됨).
- app.html `lcBorrow`→전자도서관 책(sm-+숫자brcd+elibrary)이면 `smEbookBorrowOpen(brcd,새탭)`: 빈탭→bridge→borrow→viewerUrl 이동.
- ⚠️제약: 동시이용 ~5권+14일점유, 단일계정 → 데모전용. "읽기"마다 실대출. 비우기=myBorrowList.ink의 gFnContentReturnProc('20213','<loanSrmb>','제목') 파싱→개별 return. **blind returnAll 금지**(계정에 남이 빌린 대출 존재).

## 3) 구독 크레마 — ⏳미완 (자동로그인 실험중)
- 구독=크레마클럽(cremaclub.yes24.com). 세명대=YES24 PID 344003. 접근=`/relation/crema`→YES24 Gateway(PID)→FTLogin. **(가) 기관IP/libproxy(EZproxy) 방식**(사용자 확인).
- PID만으론 서버에서 로그인 안 됨(책=로그인필요/raw bounce→개인 가입페이지). libproxy도 세션없으면 raw로 bounce. **self-contained 토큰화 불가**.
- **로그인 retUrl 지원 발견**: `POST lib.semyung.ac.kr/login?retUrl=<URL>`→그 URL로 302(외부URL도 먹음).
- 현재 시도(커밋 3d7be92): app.html `smCremaOpen`=새탭에서 자동로그인(03251)+retUrl=/relation/crema → 브라우저 JS가 기관세션 확립 기대.
- **마지막 결과=로그인 페이지 뜸**. 사용자 다른PC 로그아웃 후 재시도 예정(단일세션 충돌 의심). 재시도 시 ①세명대 도서관 로그인 vs ②YES24/크레마 로그인 구분 필요.
