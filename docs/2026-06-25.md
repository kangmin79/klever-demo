### 2) 우리 학교 대출 랭킹 = 종이책 실대출
- 기존: 전자도서관 대출베스트(순위만, 횟수 비공개) → **종이책 실대출로 전환**.

- **기간=최근 6개월**(1위 사랑의기술 25회). 30일은 대출수 과소(1위 3회)라 폐기.
- **순위 변동(지난달 대비)**: prev_rank = '한 달 전 시점의 6개월 순위'(dtf=today-212, dtt=today-30)와 비교. ▲상승 빨강 / ▼하락 파랑 / ─유지 / NEW 보라(주식식, 사용자 요청).
- 표지=알라딘 ItemSearch(Title). ⚠️괄호 시작 제목((쇼펜하우어) 등) 검색어 빈값 버그→앞괄호 제거로 수정(표지 누락 0).
- 테이블 `semyung_loan_rank`(brcd=CATTOT PK, rank/loan_count/prev_rank/isbn13/cover). `scripts/build_semyung_loan_rank.py`.

### 3) 세명대 인기 전자책 (종이책 랭킹 바로 아래)
- 전자도서관 bestContent(`SEMYUNG_BEST_LIVE`, _smFetch('best')). **순위만**(brwCnt 비공개). 변동은 날짜조회 불가→스냅샷 누적해야→사용자 "순위만으로 확정".
- 슬롯 ebookrank, mlRank live=true 재사용. 배치 보장: rank→ebookrank→newarr_p→newarr_e (injectNewArr).

### 4) 종이책 라이브 대출가능 현황 (모달)
- Edge Fn `semyung-holding?reckey=CATTOT...`(클레버/supabase/functions, 배포됨). OPAC 상세 소장현황 라이브 파싱.
- 봇체크: 검색1회 redirect:manual로 verified+JSESSIONID 쿠키 받고 상세 fetch. ⚠️`.text()` charset 오인→`new TextDecoder('utf-8').decode(arrayBuffer)` 필수.
- 파싱: callNum(청구기호)/location(자료실·층)/status(대출가능·대출중)/returnDate(반납예정). 권별 집계. 90초 캐시.
- 앱: 종이책(isbn=CATTOT) 모달에 "지금 대출 가능 N/M권 + 📍자료실 위치 + 청구기호" 또는 "대출중·반납예정일". 실시간이라 저장 안 함.
