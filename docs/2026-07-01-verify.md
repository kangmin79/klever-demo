## 검증 계획 — 에이전트별 (독립·병렬)

각 에이전트는 **service_role REST로 실제 DB를 읽어 수치로 판정**. "됐다는 주장" 재읽기 말고 **원본 대조**로 확인. 결과는 PASS/FAIL + 근거수치 + 이상 책ID 반환.

### Agent A — 해외고전 정렬 무결성 (132권)
`C:/tmp/realign_ids.txt` 전권 `classics?id=eq.<id>&select=body,body_trans,body_sent` 조회 후 책별 판정:
1. **body_sent 존재**(null 아님) — 전 132권.
2. **한국어 보존**: body_sent에서 헤더문단(길이1 且 en===ko) 제외하고 ko셀 concat, 공백제거 == `body_trans` 공백제거(정렬형=body_trans null인 책은 이 검사 skip 또는 reconstructKo 기준). 불일치 = 손상.
3. **챕터헤더 연속성**: 헤더문단(단독셀 en===ko) 개수·순서. 로마숫자/아라비아 챕터가 **빠짐 없이 순차**인지(gb-103=37, gb-98=45, gb-967=65, gb-113=27 기대). 중간 누락/역순 = 결함.

5. **FAIL 10권**: body_sent가 **null 아님**(기존 유지) 확인. 이들은 재정렬 안 됨이 정상.
- 규모 크면 표본(랜덤 30권 + 챕터많은 10권 + FAIL 10권) 우선, 나머지는 존재/보존만.
