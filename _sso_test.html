🎓 북스타 SSO 로그인 테스트

도서관 홈페이지 배너 없이, 학번·이름을 직접 넣어 로그인 전 과정을 검증합니다.

실제로는 도서관에 로그인한 학생의 학번이 자동으로 들어갑니다.
개인 기록·서재는 학번으로 저장되고, 이름은 화면 표시용입니다.
이 버튼을 누르면:
① 학번·이름이 접수 서버 sso-login으로 전송
② 서버가 school 확인 + 학번으로 Supabase 정식 계정 생성/조회
③ 북스타 앱으로 이동하며 그 학생으로 로그인 완료
→ 우측 상단 계정 칩에 이름·🎓이 뜨면 성공. 서로 다른 학번으로 두 번 해보면 계정이 갈리는지 확인 가능.
